# ことのおと — 紹介映像

アプリの映像。1920×1080・30fps・約107秒、字幕とナレーション（Gemini TTS）。Remotion 4 で作る（アプリとは別のプロジェクト）。
作り方は姉妹アプリの映像（ことのめ `../../../hangul/promo`・ことのは `../../../english/promo` など）にそろえた：アプリの画面を
描き直し、その横に一文ずつ言葉を置く。録画は使っていない。画面はアプリの CSS と言葉から、語・ピンイン・意味・高さの線は
アプリのデータ（`../public/data`）から、声はアプリ自身の声（`../public/audio`）から。

見る人：中国語の声調やピンインを知っていても、聞き分けられない人。1か所だけ違う語の組をいくつもの声で聞き比べ、
聞き分け、文の中で聞き、言ってみる。ある日ふいに分かれて聞こえてくる、を、アプリの画面で見せる。

| | 画面 | 映像の言葉 |
|---|---|---|
| 問い | 大学 dà xué と 大雪 dà xuě が erinome の声で一つずつ鳴り、鳴るあいだに、その声の高さの線が描かれる（紹介ページが見せる声と色：大学 はアクセント、大雪 は墨） | 違いが、聞こえますか？ |
| | 大学/大雪、肚子/兔子、人民/人名（紹介ページの3組） | 日本語では区別しない違い。知っていても、最初は同じに聞こえる。 |
| 名前 | アイコンと ことのおと | 知っている違いと、聞こえる違いは別のもの。 |
| 聞き比べる | 押すと組が一つずつ降る：大学/大雪 を kore、埋/买 を erinome で。大雪 を押すと降るのが止まって6組が並び、大雪 が erinome で、もう一度押すと charon で。下へ送って 聞き分けてみる | 1か所だけ違う語の組が、いくつもの声で降ってくる。／語を押すと、別の声で、もう一度。 |
| 聞き分ける | 1 / 12：糖/躺、kore の 躺 を当てる（そう、こっち。と2つの線）。2 / 12：erinome の 大学 を 大雪 と取り違える（こっちでした）。両方を押して聞き比べ、次へ | ひとつ流れて、どっちだったか選ぶ。／間違えても、点数はつけない。 |
| 違いのこと | 12問のあと：2声と3声、その作り方。取り違えた 大学/大雪 は紫で | 違いの名前は、聞き分けたあとで。／取り違えた組は、また降ってくる。 |
| 文の中で | ことのあめ の例文。出て 400 ms で「我姐也是大学生。」が例文の声で流れる。訳を見る | 同じ語が、ふだんの文の中で。 |
| 言ってみる | 大学：手本（kore）を聞いて、言ってみる（聞いています… → 線を描いています…）。線が手本の線に重なり、線は「大学」に近い、聞こえた語 大学 dà xué 通じた | 言ってみると、声の高さが線になる。 |
| 数日後 | 同じ違いの雨の 12 / 12：iapetus の 雨 をすぐに当て、1.6 秒で 違いのこと「このごろ、2声と3声が分かれて聞こえています。」 | 何度も直されるうちに、ある日、ふいに。 |
| 自分 | 自分 の 違いごと：2声と3声「10月30日 ごろから分かれて聞こえている」 | その日が、記録に残る。 |
| 終わり | 名前、タブ（聞く・自分） | 登録はいりません。記録はこの端末に残ります。 |

## 音

- ナレーション：台本は `voice/lines.json`（画面の字幕とは別の、耳で聞く文。「1か所」は「一か所」、「語を押すと」は
  「ゴースト」と聞こえたので「言葉を押すと」）。Gemini TTS（`gemini-3.1-flash-tts-preview`、声 Kore）を Vertex AI で。
  鍵は ことのおと の `.env.local`（`GOOGLE_SERVICE_ACCOUNT_KEY`・`GOOGLE_CLOUD_PROJECT`・`GOOGLE_CLOUD_LOCATION`、ことのあめ と
  同じサービスアカウント）。鍵はこのリポジトリに置かない。`--check` で書き起こして台本と並べる（V01 と V06 は作り直した）。
- 中国語の語：アプリ自身の声（`../public/audio/<voice>/<id>.mp3`、アプリが高さと聞こえ方を確かめたもの）を
  `public/app/clips` に写して使う。例文の声は ことのあめ のもの（公開の置き場から `public/app/lines/s1.wav` に）。
  ここでは作らない。Remotion の ffmpeg には ebur128 が無いので、声のある所の大きさを `scripts/assets.mjs` で測って
  そろえる（およそ -17 dBFS、ピークは -1 dBFS まで）。
- 映像の時は、声の長さから決まる（`src/voice.json`・`src/clips.json`。`src/timeline.ts` は声が言い終わってから次へ）。
  ナレーションと中国語の声は重ならない。アプリの間合い（聞き比べるの 500・380・450 ms、聞き分けるの 250 ms と 1.6 秒、
  文の中での 400 ms、言ってみるの 700 ms）はアプリのとおり。声のあいだは音楽が下がる（`src/Promo.tsx` の DUCKING）。
  声を作り直したら `music` も走らせ直す。
- 言ってみる の「学習者の声」：ここに学習者はいないので、アプリ自身の男性の声（iapetus）の 大学 を代わりにした。
  `scripts/say.mjs` がそれを、アプリの 言ってみる と同じ処理（`../src/lib/pitch.ts`・`learner.ts`・`tone.ts`）に通して
  線と「線は『大学』に近い」を出し、`/api/hear` と同じ頼み方（gpt-4o-transcribe、language zh、「以下是一个普通话词语。」）で
  何に聞こえたか（大学）を聞いた。映像はその結果（`src/say.json`）をそのまま描く。鍵は `../.env.local` の `OPENAI_API_KEY`。
- 自分 の数（浴びた雨 14 回、出会った違い 3、言ってみた語 11、違いごとの 雨 5・6・3 回、10月30日、また降ってくる組 2）は、
  映像のために置いた例（`scripts/assets.mjs` の `EXAMPLE`）。言い方はアプリの関数（`ja.me.familyRains` など）で作っている。
- 音楽と小さな音は `scripts/music.py`（ことのめ の映像のものを写し、種だけ変えた）。だれかの曲は使っていない。
- 耳で聞いての確かめ（声の感じ・速さ・音量のつり合い）は、機械ではできない。

## 作り方

```bash
cd promo
npm install
npm run assets     # アイコン、アプリの声、例文の声、アプリの言葉とデータ（src/app.json）、字（映像に出てくる字だけに切る。Python の fontTools）
npm run say        # 言ってみる の線・判定・聞こえた語（src/say.json。../.env.local の OPENAI_API_KEY）
npm run voice -- --env ../.env.local   # ナレーション（まだ無いものだけ。--force・--only V01・--check）
npm run music      # 音楽と小さな音（Python と numpy。映像の区切りに合わせて作る）
npm run studio     # 見ながら直す
npm run render     # out/kotonooto-promo.mp4
npm run card       # 一目でわかる紹介画像 out/kotonooto-card.png（src/Card.tsx）
npm run stills -- 150 990 2600     # 1コマだけ out/stills に
```

- 画面はアプリの CSS と文言から描き直している（`src/ui.tsx`、`src/scenes/`）。電話の幅 560 px を 1.4 倍で見せる。
  アプリの見た目や言葉を変えたら、ここも変える（`npm run assets` で `src/app.json` の言葉とデータは取り直せる）。
- 字（IBM Plex Sans・IBM Plex Sans JP・Noto Sans SC・しっぽり明朝）は映像に出てくる字だけに切ってある。言葉を変えたら
  `assets` を走らせ直す。
- 色は `remotion.config.ts` で bt709・yuv420p（姉妹と同じ）。
- 見せる中身は `../CONCEPT.md` のとおり：点数・正答率・連続記録は出さない。
